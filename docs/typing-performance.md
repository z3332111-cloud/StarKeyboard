# iPhone 選字回歸與效能驗證（0.3.2）

2026-10-31，針對候選詞不符合新增注音、查字延遲與選字點按困難的回報。

## 確認並修正

- 舊學習模型雙向比對簡拼，會把以 `ㄋ*` 記住的「你」帶進 `ㄋㄠ*`。新增候選現在必須符合目前輸入的音；簡拼偏好仍可替字典中真正符合的候選加分。
- 常用或學過的容錯詞可能超過正確讀音。候選排序與整句斷詞現在優先符合輸入，再比較字頻與學習分數；容錯仍保留。
- 舊模型對每一個待加分的候選掃描全部讀音。改為依音節首字索引、預先拆音節，完整讀音直接查表，再查同組簡拼。
- 字典查詢快取與學習分數快取分開；選字學習後不需重新查相同 SQLite 資料。
- iOS 學習存檔改用串行背景寫入，關閉鍵盤時完成已排入的寫入；仍使用原本的檔案保護與排除備份設定。
- 選字列取消 UIScrollView 觸控延遲，仍可滑動取消選取；上方選字列增高，第一顆字也有較完整的點按範圍。展開候選未改變時不重載格子。
