01輸入方式與語音注音、拼音、英文、滑行、韓文、日文、手寫與語音 · 8 項
iPhone・Android

注音：完整讀音或簡拼

大千注音排列，支援整句組字與分段選字；可以打完整注音和聲調，也能省略聲調、只打開頭注音，例如 ㄋㄏ 找「你好」。字典包含小麥注音字詞與日常聊天常用句。

怎麼用：選「注音」模式，點上排候選字；不確定讀音時可展開更多候選。

iPhone・Android

拼音＋繁／簡快捷切換

漢語拼音自動分音節，也支援 nh 這類聲母簡拼；需要分開音節時可用 xi'an 的半形單引號。預設輸出繁體，點候選列「繁／簡」切換，正在打的拼音會保留。

怎麼用：⚙ → 輸入法開啟「拼音」，再按中／英切到「拼」。這個按鈕控制拼音輸出，不是把其他 App 已輸入的整段文字轉換。

iPhone・Android

英文 QWERTY 與大小寫

英文排列、依輸入欄位與句子調整大寫；Shift 連按兩下可鎖定大寫，英文快速連按兩次空白可輸入句號。

怎麼用：切到英文；符號和數字可從 123、#+= 切換。自動行為可能受使用中的 App 輸入欄位影響。

iPhone・Android

英文滑行輸入

手指不放開，滑過字母後放開即可選整個單字；辨識不對時可點候選列的其他結果。

怎麼用：⚙ → 打錯字修正 → 英文滑行輸入，可隨時開關。

iPhone・Android

韓文兩排式拼字

輸入韓文子音、母音後自動組合成韓文字；可逐步刪除組字。

怎麼用：⚙ → 輸入法開啟「韓文」，再用中／英輪流切換。

iPhone・Android

日文羅馬拼音轉假名

例如 sakura 可選 さくら 或 サクラ，也會提供原本的羅馬字。現在支援平假名、片假名，尚未提供日文漢字轉換。

怎麼用：⚙ → 輸入法開啟「日文」，再用中／英切換。

平台有差異

手寫輸入

用手指寫字，停筆後顯示候選；可清空重寫，接著寫下一個字時會依畫面狀態送出上一個候選。iPhone 使用系統文字辨識，屬實驗功能；Android 使用繁中手寫模型，第一次須連網下載。

怎麼用：工具列 ✍ 或切到手寫模式。辨識效果因字跡、裝置而異，請看候選再選。

平台有差異 · v0.3.0

語音轉文字

iPhone 可點鍵盤右下的系統麥克風直接聽寫；工具列 🎙 提供操作指引。糯糯 App 另有語音頁，預設僅本機辨識，不支援時會提示；自行開啟線上辨識後，語音可能交由 Apple 處理。Android 的 🎙 會開啟語音頁，呼叫手機已安裝的辨識服務，可能連網。

怎麼用：App → 語音轉文字 → 選語言 → 開始。兩平台的語音頁均先確認、可修改文字，再複製回原 App 貼上；不會自動送出。支援語言依裝置與服務而異。iPhone 第三方鍵盤本身不能直接錄音；語音辨識與外部翻譯開關各自獨立。尚待手機實測權限與錄音。

02選字、記憶與打錯字修正常用字、前後文、標點、候選展開與容錯 · 5 項
iPhone・Android

記住常選的字詞

手動選過的字詞會在本機學習，下次相同或相關讀音可往前排；也支援簡拼選字記憶。排序仍會參考字典，不保證每次第一個都是想要的字。

怎麼用：平常點候選字即可；⚙ → 清除選字學習紀錄可重設。沒有跨裝置同步選字記憶。

兩邊都有，iPhone 加強

關聯詞與常用單字排序

兩邊都有選字後的聯想詞。iPhone 另有未打完聲調就先顯示詞語預測、參考游標前文字調整同音字，以及較長前文的接續建議；常用字頻與個人選字習慣一起參與排序。

怎麼用：⚙ → 輸入法 → 聯想詞。這些建議在本機計算，Android 尚未包含本次 iPhone 的完整前文排序改善。

iPhone

候選列快速加標點

中文字選好後，可在候選列點逗號、句號、問號、驚嘆號；遇到「怎麼」「有沒有」或問句結尾等線索時，優先推薦問號。這是文字規則判斷，不一定每次都猜對。

怎麼用：選好中文字後看上排，不必每次切到符號頁。標點與聯想詞可一起出現。

兩邊都有，iPhone 加強

看清注音、展開更多候選

按下拉箭頭可展開候選面板；第一個候選有明顯底色。iPhone 會在候選列上方保留實際按過的注音與聲調，長內容可左右滑查看，並已改善換字閃動及候選面板與按鍵重疊。

怎麼用：按候選列右側的下拉箭頭，選字或返回鍵盤。Android 的組字文字主要顯示在正在輸入的欄位，與 iPhone 上排注音呈現不同。

iPhone・Android

英文修正＋注音容錯

英文提供拼字建議，按空白或標點時可自動修正；改錯了立刻按刪除可復原。注音可開啟相鄰鍵容錯、聲調容錯，以及 ㄣ／ㄥ、ㄓ／ㄗ、ㄔ／ㄘ、ㄕ／ㄙ 模糊音。

怎麼用：⚙ → 打錯字修正，各項可分別開關。容錯是提供候選，不會保證猜中。

03聊天、符號與翻譯工具表情、顏文字、自製貼圖、花式文字與快捷片語 · 8 項
iPhone・Android

數字、符號與全形／半形

注音的 123 頁和 iPhone 注音鍵盤同一排列：- / ： ； （ ） $ @ 「 」，第三排是 。 ， 、 ？ ！ .。英文 123 頁也對齊 iPhone。#+= 的 ` * _ ~ | # \ ^ + = { } [ ] < > %` 一律半形，方便 Discord 和程式碼；～ — 『』 … 這類中文標點維持全形。

怎麼用：123 → #+=。程式符號不用再切半形。

iPhone・Android

表情符號與特殊符號分類

☺ 提供人物、動物、食物等表情分類與最近使用。※ 提供常用、括號、標點、箭頭、數學、單位、圈圈數字、希臘字母、框線、日文假名與注音。

怎麼用：工具列 ☺ 或 ※，滑動下方分類找需要的項目。

iPhone・Android

顏文字與我的表符

內建開心、愛心、難過、生氣、驚訝、害羞、動物、打招呼等顏文字。可自行打字、拼出顏文字或從剪貼簿新增到「我的」，並保留最近使用；長按自製項目可進入刪除。

怎麼用：工具列 (•ᴗ•) → 我的，或 ☺ → ⭐ → ＋。

平台有差異

照片做成自己的貼圖

可把圖片存成常用貼圖。iPhone 點貼圖後先複製，再到輸入框長按貼上；Android 會嘗試插入圖片，不支援的 App 則改用複製貼上。能否貼圖片取決於使用中的 App。

怎麼用：iPhone：App 挑照片或相簿拷貝 → ☺ → ⭐ → ＋ → 圖片做成貼圖。Android：App → 挑一張照片做成貼圖。

iPhone・Android

21 種花式文字

草寫、粗體、斜體、哥德、打字機、圈圈、黑圈、方塊、小型大寫、全形、倒過來、刪除線、底線、波浪、愛心、閃亮、星星、花花、括號、標題、一字一星。字母變體以英文為主，裝飾也可搭配中文。

怎麼用：工具列 𝒜 → 輸入文字 → 變花樣 → 點結果送出。這是特殊文字，不同 App／字型的顯示可能不同。

iPhone・Android

自訂快捷片語

把常用整段話配上縮寫，例如 addr 對應地址；打英文縮寫、中文縮寫或對應的簡拼時，可從候選列選整段送出。支援新增與刪除。

怎麼用：⚙ → 快捷片語 → ＋ 新增，先填內容，再填縮寫。

iPhone・Android

游標與日常操作

按住空白鍵左右滑動可移動游標；按住刪除可連續刪字。中／英輪流切換已啟用模式，工具列可收起鍵盤；送出鍵會依輸入欄位顯示傳送、搜尋、完成等用途。

怎麼用：iPhone 用 🌐 切其他鍵盤；Android 長按中／英叫出系統鍵盤選擇。

平台有差異

多語翻譯與原文語言選擇

可選原文語言或自動判斷，再翻成英、日、韓、繁中、簡中、法、德、西班牙、義大利、泰、越南、印尼文。點翻譯結果即可送出，也可回去修改原文。

怎麼用：工具列「譯」→ 從：原文語言／→ 目標語言 → 翻譯。iPhone 的系統翻譯需符合版本與語言資料條件；Android 可下載離線模型，但目前翻成繁中會走外部服務。外部 MyMemory 翻譯須先在 ⚙ → 隱私與安全開啟，最多傳送 450 字；預設關閉。

05剪貼簿保存與搬家手動保存、釘選、資料夾分類、JSON 備份與匯入 · 4 項
iPhone・Android

保存、釘選與整理紀錄

可手動加入目前複製的文字、點一下貼出、釘選、只看釘選、逐筆刪除，以及「清暫存」移除未分類且未釘選的內容。暫存上限可選 50／100／200／500 筆，預設 200；已分類與釘選另行保留。

怎麼用：工具列剪貼簿。自動記錄預設關閉，需在 ⚙ → 隱私與安全開啟；只在鍵盤使用期間捕捉複製內容，不是全天候監看。iPhone 支援左右滑動管理項目。

iPhone・Android

JSON 匯出、檔案匯入

匯出 JSON 保留多行文字、順序、釘選與分類（含空分類），iPhone 和 Android 共用格式；可匯入 JSON 或 UTF-8 TXT（每行一筆）。先預覽再匯入，重複文字合併，保留原有紀錄；容量不足會跳過新內容並顯示筆數。

怎麼用：剪貼簿 → 匯入／匯出；Android App 首頁也能開啟。每次最多 2 MB／1,000 筆，單筆最多 20,000 字。iPhone 選檔介面仍需實機確認。

iPhone・Android

從其他鍵盤搬家

先在原鍵盤匯出檔案，或複製文字清單，再到這裡匯入。支援 JSON 文字陣列、items 清單，以及 text／content 欄位；貼上清單時可選每行一筆或整段一筆，保留換行。

怎麼用：原鍵盤沒有匯出功能時，需先手動複製；不能直接讀取別的鍵盤私人資料。匯出檔是明文，存到雲端可能同步，請先移除敏感內容。

iPhone・Android · v0.3.1

自己命名的剪貼簿分類

預設只有「全部、📌 釘選」，不會預先建立資料夾。按側邊固定的「＋」，在鍵盤上方的命名小框輸入名稱，按「建立」後才會在釘選旁出現自己的資料夾分頁；取消不會新增。分類多時可左右滑動，側邊的「＋」一直保留。最多 50 個分類，名稱 1～40 字；每筆可移到一個分類，釘選可同時保留。改名會同步更新內容；移除分類只把內容放回未分類，不刪文字。放進分類的內容不受暫存上限及「清暫存」影響。

怎麼用：剪貼簿側邊「＋」→ 命名小框 → 建立；每筆右側 📁 選目的地；「資料夾管理」改名或移除。JSON 匯出保留空分類，匯入合併同名分類；重複文字以已有分類優先。新版備份需 v0.3.0 以上讀取，舊版備份仍可匯入。尚待手機實測分頁操作。

06隱私、App 與版本更新預設開關、資料保護、試打、安裝與續簽 · 3 項
iPhone・Android

隱私開關與本機資料保護

自動剪貼簿紀錄、外部網路翻譯預設關閉。會跳過有敏感標記的剪貼簿，但無法辨識所有密碼。iPhone 的剪貼簿、學習與快捷片語檔案套用完整檔案保護及不備份設定；Android 關閉 App 備份並設定排除規則。

怎麼用：⚙ → 隱私與安全；App 有完整風險說明。選字記憶與片語留在本機，解除安裝仍可能失去資料，手動匯出的檔案不在這些保護範圍內。

iPhone・Android

App 試打、說明與新版提醒

App 提供鍵盤開啟步驟、試打欄位、照片／貼圖入口與隱私說明。App 和鍵盤會向 GitHub 檢查新版並顯示更新內容；公開版本使用 v0.2.0 這類小版本號。Android 遇到鍵盤錯誤時可在 App 複製診斷紀錄協助排查。

怎麼用：打開桌面上的「糯糯鍵盤」。版本查詢不包含打字或剪貼簿內容；下載更新仍需自行安裝。

平台有差異

安裝網站、自動建置與 Wi-Fi 續簽

網站可預覽造型配色、選字／標點／快捷片語示意及試聽。GitHub 在程式更新後自動測試打包，網站指向已發布安裝檔。iPhone 首次插線配對後，可設定 Sideloadly Daemon 透過 Wi-Fi 自動續簽；Android 不需要每週續簽。

怎麼用：免費 Apple ID 簽章有效 7 天，無線續簽需要電腦喚醒、Daemon 執行、手機在可互通的同一網路。Daemon 不會自動抓新版 IPA；完整步驟在下方安裝教學。

先從最常用的開始：切換輸入法看「01」，打字選字看「02」，聊天小工具看「03」，換外觀看「04」，搬剪貼簿看「05」。

電腦只需要用一次。裝好之後，更新都在 iPhone 上做：下載新的 .ipa → 打開 LocalDevVPN → SideStore 左上角 ＋ → 選檔案 → 蓋過舊版。不用每 7 天再插線。SideStore 會自己幫免費 Apple ID 的 7 天開發者簽章續期，也可以在背景續期。

免費帳號最多同時 3 個側載 App（SideStore 自己算 1 個），每 7 天最多 10 個 App ID。SideStore 加上糯糯鍵盤用掉 2 個名額。只裝這個鍵盤不需要 Sideloadly、LiveContainer、iCloud，也不用另外的 USB 無線網卡。如果已經裝了 LiveContainer，建議移除，免得佔掉第三個名額。

兩條路

  • Windows：iTunes 或 Apple Devices → iloader → SideStore → LocalDevVPN
  • Mac：iloader → SideStore → LocalDevVPN。macOS 10.15 Catalina 以後，信任和辨識 iPhone 在「訪達」；Mojave 和更早的系統才用 iTunes。
  1. 在電腦安裝讓 Windows 認得 iPhone 的軟體，兩種擇一：
    • Apple 官網的 iTunes（64 位元）
    • 或 Apple Devices（Apple 官方說明，安裝檔在 Microsoft Store）
    接著安裝 iloader。官方只從 iloader.app 和 GitHub 發行頁 下載。Windows 用 MSI 安裝程式。
  2. 在 iPhone 的 App Store 安裝 LocalDevVPN。之後每一次安裝、更新、續期都要先打開它。
  3. 用傳輸線把 iPhone 接到電腦，解鎖手機。手機跳出「要信任這部電腦嗎？」按信任並輸入密碼。電腦如果也問，一樣按信任。
  4. 打開 iloader，用 Apple ID 登入，選你的 iPhone，按 Install SideStore (Stable)。有兩步驟驗證就輸入驗證碼。
    不放心可以把密碼交給專門註冊、只拿來簽名的 Apple ID。
  5. 在 iPhone：設定 › 一般 › VPN 與裝置管理，點你的 Apple ID，按信任。需要開發者模式的 iOS，再到 設定 › 隱私權與安全性 › 開發者模式 打開，手機會重新開機，開機後再確認一次。
  6. 先打開 LocalDevVPN 並連上。再打開 SideStore，用剛剛在 iloader 登入的同一個 Apple ID 登入。說明見 sidestore.io 和 安裝前提。
  7. SideStore → My Apps，點 SideStore 旁邊的 7 DAYS，先續期一次，設定才算完成。

  1. 加入鍵盤：設定 › 一般 › 鍵盤 › 鍵盤 › 新增鍵盤…，往下找到「第三方鍵盤」，選糯糯鍵盤。

放自己的背景照片（iPhone）

  1. 打開「照片」App，點開想用的照片，按左下角的分享 › 拷貝。

之後更新（都在手機上）

  1. 用 iPhone 打開這一頁，下載新的 .ipa。
  2. 打開 LocalDevVPN，確認已連上。
  3. 打開 SideStore，左上角 ＋，選剛下載的安裝檔，蓋過舊的糯糯鍵盤。延伸功能仍選 Keep App Extensions (Use Main Profile)。

其他方法（備用）

用 Sideloadly 從電腦安裝

平常請用上面的 SideStore。只有 SideStore 裝不起來時，才用 Sideloadly 把 StarKeyboard.ipa 從電腦裝進手機。Windows 仍要先裝 Apple 官網的 iTunes。細節見 Sideloadly 官方 FAQ。

Sideloadly 的自動續簽要電腦醒著、Daemon 在跑，手機和電腦在同一個網路。它不會自己下載 GitHub 上的新版。這種裝法也不需要 iCloud。裝好之後若改回 SideStore，LiveContainer 請不要留著，以免佔掉免費帳號的第三個名額。

裝新版

有新版時，打開「糯糯鍵盤」App 最上面會出現「有新版」和下載按鈕；或直接按這一頁的「下載 Android 安裝檔」。

  2. 移除舊版：長按「糯糯鍵盤」圖示 › 解除安裝。

常見問題

iPhone：App 一打開就閃退，或說「無法驗證 App」
請確認所需的開發者模式與開發者信任已設定。也可能是簽章到期：先檢查 Daemon 是否執行、手機是否能被找到，再手動 Refresh。詳見上方 Wi-Fi 自動續簽教學。
iPhone：Sideloadly 找不到手機
先解鎖手機、開啟 iTunes 確認是否看得到裝置。無線連線需先完成一次插線配對與 Wi-Fi 同步設定，手機和電腦在同一個區域網路；仍找不到再換傳輸線或 USB 孔。
iPhone：Sideloadly 說 App ID 數量到上限
免費帳號 7 天內最多建立 10 個 App ID。等幾天，或改用另一個 Apple ID。
iPhone：鍵盤清單裡找不到糯糯鍵盤
先打開一次「糯糯鍵盤」App，再把手機重新開機。
iPhone：打密碼的時候變回原本的鍵盤
這是 iOS 的規定，所有第三方鍵盤在密碼欄都會被換掉，不是壞掉。
Android：顯示「未安裝應用程式」
可能是新舊安裝檔簽章不同，或裝置／安裝權限問題。請先保留舊 App、確認安裝來源與錯誤訊息；若確定需要重裝，先在舊鍵盤匯出剪貼簿備份。解除安裝會刪掉本機紀錄、設定與學習資料。
Android：鍵盤突然叫不出來、變回原本的鍵盤
鍵盤當掉或清除過資料時，手機會自動換回內建鍵盤。打開「糯糯鍵盤」App 再按一次 ① ②。如果 App 最上面出現「⚠️ 鍵盤出過問題」，按「複製紀錄」傳給把這頁給你的人。
剪貼簿沒有記到
先到鍵盤 ⚙ → 隱私與安全開啟自動記錄。iPhone 還需允許完整取用；只在鍵盤使用時記錄，標示為敏感的內容會跳過。也可以在剪貼簿按「＋」手動保存。
注音一直跳出奇怪的字
點正確的候選字，鍵盤會記住你常選的字，越用越順。也可以多打一點注音或打聲調，會更準。

隱私與安全

新版預設關閉自動剪貼簿紀錄與外部網路翻譯。可在鍵盤 ⚙ → 隱私與安全自行開啟；敏感標記無法辨識所有密碼，請先清理舊紀錄。完整風險說明已放在 App 的「隱私與安全」。
