拼音直接打繁體，剪貼簿也能搬家

拼音繁／簡切換：切到拼音後，按候選列右側的「繁／簡」。顯示「繁」時就會送出繁體字；正在打的拼音會保留。

剪貼簿匯入／匯出：鍵盤 → 剪貼簿 →「匯入／匯出・剪貼簿搬家」。Android 也可從 App 首頁開啟。JSON 保留多行內容和釘選，iPhone 與 Android 可互相搬移；TXT 每行視為一筆。

  1. 在舊鍵盤找「匯出／備份」或「全選複製」，將內容存為 JSON／UTF-8 TXT，或複製文字清單。
  2. 在糯糯鍵盤選「匯入檔案」或「匯入目前複製的文字」。貼上時可選每行一筆，或整段保留換行。
  3. 查看預覽後按匯入。重複文字會合併，原有紀錄會保留，超過未釘選容量的新內容會跳過並顯示筆數。

支援 JSON 文字陣列、items 清單，以及 text／content 文字欄位。每次最多 2 MB、1,000 筆，單筆最多 20,000 字。其他鍵盤若沒有匯出功能，需要先手動複製內容；無法直接讀取它的私人資料。

匯出檔是明文；存到雲端可能同步或備份。先檢查有沒有密碼、驗證碼與私密內容，並妥善保存或刪除檔案。

第一次用電腦與傳輸線安裝，之後可設定 Wi-Fi 自動續簽，不用每週插線。免費 Apple ID 的簽章有效 7 天；續簽時電腦須開著、Daemon 有執行，手機與電腦能在同一個區域網路互相找到。

iPhone 上的設定（只要做一次）

  1. 打開開發者模式：設定 › 隱私權與安全性 › 開發者模式，打開後手機會重新開機，開機後再按一次「開啟」並輸入密碼。
    要先用 Sideloadly 裝好 App，這個選項才會出現。
  2. 信任開發者：設定 › 一般 › VPN 與裝置管理，點你的 Apple ID（開發者 App 下面那一個），按「信任」。
  3. 加入鍵盤：設定 › 一般 › 鍵盤 › 鍵盤 › 新增鍵盤…，往下找到「第三方鍵盤」，選糯糯鍵盤。
  4. 允許完整取用：回到鍵盤清單點「糯糯鍵盤」，打開「允許完整取用」，跳出提醒時按「允許」。
    剪貼簿紀錄、按鍵聲音、震動、貼圖、背景照片、翻譯、檢查新版都需要它。
  5. 開始打字：到任何能打字的地方（LINE、備忘錄都可以），按住左下角的 🌐 地球鍵，在跳出的清單選「糯糯鍵盤」。之後按一下地球鍵就能在鍵盤之間切換。
  6. 想看說明或試打，打開桌面上的「糯糯鍵盤」App。

放自己的背景照片（iPhone）

  1. 打開「照片」App，點開想用的照片，按左下角的分享 › 拷貝。
  2. 叫出糯糯鍵盤，按上面工具列的 ⚙ 設定 › 背景照片 › 從剪貼簿貼上圖片。
  3. 鍵盤會直接進入調整：一指拖拉移動照片、兩指捏合放大縮小，看到的就是之後的樣子。調好按完成。
  4. 之後想再調：⚙ 設定 › 調整照片位置和大小。「照片淡化」和「按鍵透明度」可以讓字更清楚。
  5. 可以放好幾張：再拷貝別張照片，按「＋ 從剪貼簿新增照片」。設定裡點縮圖換照片，也可以選固定這張、每次打開換、每天換。每張照片的位置和大小各自記住。

設定 Wi-Fi 自動續簽

第一次用線配對，之後讓 Sideloadly Daemon 在簽章快到期時自動續簽。不用等到第 7 天才開電腦，也不用每週插線。

  1. 首次連線設定：用傳輸線連接並解鎖 iPhone。Windows 打開 iTunes，選手機圖示 › 摘要 › 選項，勾選「透過 Wi-Fi 與此 iPhone 同步」，按套用／同步。Mac 在 Finder 選 iPhone › 一般，勾選「在 Wi-Fi 連線時顯示此 iPhone」，再套用／同步。
  2. 加入續簽清單：在 Sideloadly 開啟自動續簽（Automatic Refresh），用原本的 Apple ID 安裝糯糯鍵盤。完成後，在工作列通知區／選單列的 Sideloadly Daemon 確認清單有糯糯鍵盤；依目前版本選單開啟登入時啟動。
  3. 拔線驗證：手機與電腦連到同一個區域網路，拔掉傳輸線，確認 Sideloadly 仍找得到 iPhone，再從 Daemon 對糯糯鍵盤執行一次手動 Refresh。成功後才算無線流程設定完成。
  4. 平常使用：電腦開機且保持喚醒、Daemon 持續執行，讓 iPhone 在到期前有機會連回同一網路。找不到手機時先解鎖螢幕、開啟 iTunes，檢查是否用了隔離裝置的訪客 Wi-Fi。

電腦關機、睡眠，或手機長時間不在同一網路時，無法續簽。若已到期，回到可連線的環境手動 Refresh；無線仍失敗時再插線。沿用原 Apple ID 與 App 識別碼，不要先刪掉舊 App，以保留資料。

依 Sideloadly 官方 FAQ 整理。Apple ID 密碼與驗證碼只在你信任的本機安裝工具輸入，請勿上傳到 GitHub。

自動建置、續簽，與安裝新版

GitHub 自動建置：程式更新後會測試、打包，再發布安裝檔；這個網頁會取得最新已發布版本。

Daemon 自動續簽：延長電腦裡已登錄版本的使用期限，不會自動下載 GitHub 的新版 IPA。

要更新功能時，在電腦下載最新 StarKeyboard.ipa，用相同 Apple ID、相同 App 識別碼，保留自動續簽設定，再用 Sideloadly 安裝一次；Wi-Fi 配對成功後可無線安裝。這會更新 Daemon 保存的版本。不用刪除舊 App，設定和資料可保留。

怎麼用

iPhone 和 Android 都有以下常用功能；介面與部分新功能會依平台、版本不同。工具列在鍵盤最上面那一排；⚙ 是鍵盤設定。

注音：不打聲調也可以

打到一半上面就會先出字。可以只打每個字開頭的注音，連打好幾個字再一起選：ㄨㄛㄏㄓㄜㄧ → 我會這樣、ㄋㄏ → 你好。打聲調也可以，會更準。

拼音（給習慣拼音的朋友）

到 ⚙ › 輸入法 打開「拼音」，按 中／英 切過去。打 nihao 或只打聲母 nh 都會出「你好」。預設是繁體字，想要簡體在設定裡打開「拼音輸出簡體字」。

𝒜 花式文字

按工具列的 𝒜，打字後按「變花樣」，點一個樣式送出。對方也看得到：𝓼𝓽𝓪𝓻、ⓢⓣⓐⓡ、刪̶除̶線̶、♡ 愛心 ♡。英文的樣式最多。

快捷片語

⚙ › 快捷片語 › ＋ 新增：先打整段話（例如地址），再打縮寫（例如「地址」或 addr）。之後打縮寫，候選字第二個就是整段話。

英文滑行輸入

英文鍵盤上手指不要放開，依序滑過字母再放開，就會打出整個字，例如滑過 h→e→l→o 出 hello。認錯了就點上面列出的別的字。不想用可以在 ⚙ › 打錯字修正 關掉。

字體、主題、特效、按鍵音

⚙ 裡可以換主題顏色、按鍵造型（圓角、果凍、貓耳、雲朵、兔兔、狗狗、布丁、水母、火焰、水滴、鴨鴨）、字體（粉圓、芫荽、文楷）、按鍵特效（按下去冒出星星、愛心、花花…），還有可愛按鍵音（iPhone：系統聲、柔和叮叮；Android：泡泡、木琴、叮鈴、啵啵）。字體只改變你鍵盤上的樣子。

剪貼簿、表符、翻譯、手寫

剪貼 可手動保存文字，也能在 ⚙ → 隱私與安全開啟自動記錄（預設關閉），請勿保存密碼。☺ 表情、(•ᴗ•) 顏文字、譯 先打中文再翻成外文、✍ 用手指寫字。

常見問題

iPhone：App 一打開就閃退，或說「無法驗證 App」
請確認所需的開發者模式與開發者信任已設定。也可能是簽章到期：先檢查 Daemon 是否執行、手機是否能被找到，再手動 Refresh。詳見上方 Wi-Fi 自動續簽教學。
iPhone：Sideloadly 找不到手機
先解鎖手機、開啟 iTunes 確認是否看得到裝置。無線連線需先完成一次插線配對與 Wi-Fi 同步設定，手機和電腦在同一個區域網路；仍找不到再換傳輸線或 USB 孔。
iPhone：Sideloadly 說 App ID 數量到上限
免費帳號 7 天內最多建立 10 個 App ID。等幾天，或改用另一個 Apple ID。
iPhone：鍵盤清單裡找不到糯糯鍵盤
先打開一次「糯糯鍵盤」App，再把手機重新開機。
iPhone：打密碼的時候變回原本的鍵盤
這是 iOS 的規定，所有第三方鍵盤在密碼欄都會被換掉，不是壞掉。
Android：顯示「未安裝應用程式」
手機裡還有舊版。先長按圖示解除安裝，再點新的安裝檔。
Android：鍵盤突然叫不出來、變回原本的鍵盤
鍵盤當掉或清除過資料時，手機會自動換回內建鍵盤。打開「糯糯鍵盤」App 再按一次 ① ②。如果 App 最上面出現「⚠️ 鍵盤出過問題」，按「複製紀錄」傳給把這頁給你的人。
剪貼簿沒有記到
先到鍵盤 ⚙ → 隱私與安全開啟自動記錄。iPhone 還需允許完整取用；只在鍵盤使用時記錄，標示為敏感的內容會跳過。也可以在剪貼簿按「＋」手動保存。
注音一直跳出奇怪的字
點正確的候選字，鍵盤會記住你常選的字，越用越順。也可以多打一點注音或打聲調，會更準。

隱私與安全

新版預設關閉自動剪貼簿紀錄與外部網路翻譯。可在鍵盤 ⚙ → 隱私與安全自行開啟；敏感標記無法辨識所有密碼，請先清理舊紀錄。完整風險說明已放在 App 的「隱私與安全」。
