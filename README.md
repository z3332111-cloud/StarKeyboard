# 糯糯鍵盤 StarKeyboard

支援 iOS 15 以上的 iPhone 鍵盤：注音、手寫、英文、數字、特殊符號、表情符號、日式顏文字、自製表符／貼圖、剪貼簿紀錄、可愛主題（可放自己的照片當背景）。

## 功能

| 功能 | 說明 |
|---|---|
| 注音（大千） | 整段注音一起選字（詞頻＋動態規劃，和麥注音同一類做法）、點候選字一段一段選、聯想詞、會記住你常選的字。字典來自[小麥注音](https://github.com/openvanilla/McBopomofo)（MIT 授權），鍵盤打開時讀進記憶體 |
| 手寫 | 用 iPhone 內建的文字辨識（Vision），寫完停一下就辨識。**實驗功能** |
| 拼音 | 漢語拼音（馬來西亞、中國用），自動斷音節（xi'an 用 ' 分開）、整句選字、簡拼（nh → 你好）、預設輸出繁體字（可切簡體）；要在設定打開 |
| 韓文 | 兩排式，子音母音自動拼成字（要在設定打開） |
| 日文 | 打羅馬拼音變假名（sakura → さくら／サクラ），還沒有漢字轉換（要在設定打開） |
| 翻譯 | 工具列「譯」：先打中文再翻成英、日、韓、法、德、西、泰、越、印尼文等；iOS 26 以上用 iPhone 內建翻譯，不行就用網路翻譯 MyMemory |
| 打錯字修正 | 英文按空白自動修正（馬上按刪除可復原），打字時列出拼字建議；注音按到旁邊的鍵、聲調打錯也猜得到，模糊音（ㄣㄥ、ㄓㄗ、ㄔㄘ、ㄕㄙ）可在設定打開 |
| 英文 | QWERTY、自動大寫、兩下空白變句號、Shift 連按兩下鎖定大寫 |
| 數字／符號 | 注音 123 頁和 iPhone 一樣（。，、？！和「」）；英文 123 頁也對齊 iPhone。`#+=` 放其餘符號 |
| 特殊符號 ※ | 常用、括號、標點、箭頭、數學、單位、圈圈數字、希臘、框線、日文假名、注音 |
| 表情符號 ☺ | 分類＋最近使用 |
| 顏文字 (•ᴗ•) | 開心、愛心、難過、生氣、驚訝、害羞、動物、打招呼、其他 |
| 我的表符 ⭐ | 自己打一個、從剪貼簿加文字、把圖片做成貼圖（點一下複製，再貼上）；長按進入刪除模式 |
| 剪貼簿 📋 | 自動記錄（最多 50～500 筆）、釘選、左右滑動刪除／釘選、只看釘選 |
| 主題 ⚙️ | 8 種配色、11 種按鍵造型（圓角／果凍／貓耳／雲朵／兔兔／狗狗／布丁／水母／火焰／水滴／鴨鴨）、自訂背景照片、淡化、按鍵透明度 |
| 大小 ⚙️ | 鍵盤高度（80%～130%）、字的大小、按鍵間距都能用滑桿調，邊拖邊看 |
| 其他 | 按住空白鍵左右滑移動游標、按鍵聲音與震動 |

## iOS 的限制（不是 bug）

- **剪貼簿**：iOS 不讓鍵盤在背景讀剪貼簿，所以是「鍵盤打開的時候」才記錄剛複製的東西（鍵盤開著時每秒檢查一次）。
- **允許完整取用**：剪貼簿、聲音、震動、貼圖、背景圖都需要在設定裡開啟。
- **密碼欄、電話撥號**：iOS 會強制換回系統鍵盤。
- **貼圖**：鍵盤沒辦法直接把圖片打進輸入框，所以是點一下複製，再到輸入框長按「貼上」。

## 怎麼裝到 iPhone（沒有 Mac 也可以）

1. 這個專案放在 GitHub 上，每次更新程式，GitHub 會用雲端 Mac 自動打包（`.github/workflows/build.yml`）。
2. 到 GitHub 專案的 **Releases** 下載最新的 `StarKeyboard.ipa`。
3. 在 Windows 安裝 [Sideloadly](https://sideloadly.io/)＋ iTunes（要從 Apple 官網下載的版本，不是 Microsoft Store 版）。
4. iPhone 用傳輸線接電腦，打開 Sideloadly，把 ipa 拖進去，輸入 Apple ID，按 Start。
5. iPhone：設定 › 一般 › VPN 與裝置管理 › 信任你的 Apple ID。iOS 16 以上還要打開：設定 › 隱私權與安全性 › 開發者模式。
6. 設定 › 一般 › 鍵盤 › 鍵盤 › 新增鍵盤 › 糯糯鍵盤，再點進去打開「允許完整取用」。

免費 Apple ID 裝的 App 每 7 天會過期，用 Sideloadly 再裝一次就好（設定和剪貼簿紀錄不會不見）。

## 專案結構

```
Core/        注音組字、選字引擎、剪貼簿、表符資料（純邏輯，有自動測試）
Keyboard/    鍵盤擴充功能（畫面、按鍵、面板、手寫）
App/         外殼 App（安裝說明、試打、挑照片）
tools/       build_dict.py：把小麥注音的字典轉成 SQLite
project.yml  XcodeGen 專案設定（雲端打包時產生 Xcode 專案）
```
